Jogo 2 — Acerta o Alvo

Como jogar:
- Abra `index.html` no seu navegador.
- Clique em "Iniciar" para começar o jogo (30 segundos).
- Clique no alvo que aparecer para ganhar pontos.
- Quando o tempo acabar, sua pontuação será mostrada.

Dicas:
- Você pode pressionar `Space` para iniciar rapidamente.
- Use `Reiniciar` para resetar a partida.

Arquivos:
- `index.html` — interface do jogo
- `style.css` — estilos
- `script.js` — lógica do jogo

Feito rapidamente para demonstração; posso transformar isso em um projeto mais completo (pontuações, níveis, mobile tweaks) se desejar.
